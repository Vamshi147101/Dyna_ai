Introducing DYNA-bot - the smart chatbot that lets you converse directly with your simulation models! 

Instead of manually hunting down *PART, *MAT, or *CONTACT cards across multiple .k files, simply ask DYNA-bot what you need to know.

Why DYNA-bot?

  * Zero Keyword Hunting: Skip opening the raw text files entirely.
  * Total Clarity: Ask natural questions and get instant insights about any component, material definition, or parameter.
  * Faster Engineering: Spend less time decoding inputs and more time analyzing actual results.

You can literally know everything in your model, just by asking.

How to use:
  1. pull the code to local pc. 
  2. Create virtual env and install all the dependencies.
  3. Run the app.py code which opens up the Dyna bot tool interface.
  4. Get a gemini API key from the gemini api website and paste the key in the tool.
  5. Start asking the bot anything about Ls dyna/ K files.
